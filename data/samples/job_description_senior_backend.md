# Senior Backend Engineer, Platform

Northwind Cloud is hiring a senior backend engineer to own the event ingestion
platform that every product team builds on.

## Requirements

- Five or more years building production backend services in Python or Go
- Deep experience with event-driven architecture, ideally Kafka or Azure Event Hubs
- Strong data modelling: you have chosen partition keys and lived with the consequences
- Production experience on Azure, including Azure Functions and Cosmos DB
- You have carried a pager and improved the systems that woke you up

## Nice to have

- Terraform or Bicep for infrastructure as code
- Observability tooling: Prometheus, Grafana, or Azure Monitor
- Experience migrating services off a shared database

## What you will do

- Design and operate the ingestion path for several billion events per month
- Set the data modelling standards other teams follow
- Take part in the on-call rotation for the platform
